因此想要借着中秋节写这样一个搞怪的模组，增加使用铜配方的各种月饼。

首先是基本月饼的合成，使用游戏中常见的材料，比如可可豆。月饼的材料应该是原版具有的，比如可以制作可可豆月饼，南瓜月饼，莲蓉月饼。

1. 可可豆和装满水的炼药锅交互，会变成可可豆豆沙，
2. 通过四个小麦，一个糖，一个鸡蛋，制作月饼面团。
3. 四个月饼面团+一个可可豆豆沙制作面饼
4. 使用一个木棍一个铁制作月饼模具
5. 将月饼面团作为一个方块放置，使用月饼模具对着月饼面团右键，或者压印图形的月饼面团
6. 将月饼面团放在熔炉中烤制可获得完整月饼

- 此状态的月饼可以食用，恢复一定饱食度
- 此状态的月饼可以和烟花合成，能够获得月饼形状的烟花

月饼可以和各种铜进行合成，得到上述的各种奇怪月饼。
- 在这个情况的月饼使用，恢复饱食度的同时可能会扣1点血，因为太硬了
- 月饼可以丢出去，造成伤害
- 月饼可以作为弩的弹药，伤害加倍
- 考虑使用剑与铜月饼合成，那么可以拆分称两份，再次合成可以变成两个四分之一份，然后不同的月饼块能够合成称为一个奇怪配方的月饼。比如
四分之一斑驳，四分之一锈蚀，四分之一氧化，四分之一铜月饼
